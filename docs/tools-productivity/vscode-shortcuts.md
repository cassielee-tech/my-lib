# VS Code 快捷键速查

按使用频率从高到低排列，只收真正高频的条目。以 macOS 默认键位为准（Windows / Linux 大多数情况把 `⌘` 换成 `Ctrl`、`⌥` 换成 `Alt` 即可）。

## 1. 每天用几十次

| 功能 | 快捷键 |
| --- | --- |
| 命令面板（一切功能的入口，忘记快捷键时的兜底） | `⌘ ⇧ P` |
| 快速打开文件（输入文件名模糊匹配） | `⌘ P` |
| 保存 / 全部保存 | `⌘ S` / `⌥ ⌘ S` |
| 查找 / 替换（当前文件） | `⌘ F` / `⌥ ⌘ F` |
| 全局搜索 / 全局替换（整个工作区） | `⌘ ⇧ F` / `⌘ ⇧ H` |
| 添加下一个相同词为光标（连按选中多处，多光标编辑） | `⌘ D` |
| 在下方 / 上方添加光标 | `⌥ ⌘ ↓` / `⌥ ⌘ ↑` |
| 删除当前行 | `⇧ ⌘ K` |
| 向下复制当前行 | `⇧ ⌥ ↓` |
| 上移 / 下移当前行 | `⌥ ↑` / `⌥ ↓` |

## 2. 编辑与导航

| 功能 | 快捷键 |
| --- | --- |
| 跳转到定义 | `F12` |
| 返回上一个光标位置（看完定义跳回来） | `⌃ -` |
| 查看引用 | `⇧ F12` |
| 重命名符号（全项目同步改） | `F2` |
| 快速修复（灯泡动作） | `⌘ .` |
| 格式化文档 | `⇧ ⌥ F` |
| 行注释 / 块注释 | `⌘ /` / `⇧ ⌥ A` |
| 跳转到文件内符号（函数、变量名直达） | `⌘ ⇧ O` |
| 跳转到行 | `⌃ G` |
| 扩大 / 缩小选中范围 | `⌃ ⇧ ⌘ →` / `⌃ ⇧ ⌘ ←` |

## 3. 界面与终端

| 功能 | 快捷键 |
| --- | --- |
| 显示 / 隐藏侧边栏 | `⌘ B` |
| 打开 / 关闭集成终端 | `⌃ `` ` |
| 新建终端 | `⌃ ⇧ `` ` |
| 显示 / 隐藏面板 | `⌘ J` |
| 问题面板（编译错误与告警列表） | `⇧ ⌘ M` |
| 拆分编辑器（左右分屏） | `⌘ \` |
| 切换标签页 | `⌃ Tab` / `⌃ ⇧ Tab` |
| 关闭当前标签页 | `⌘ W` |

## 4. 按需取用

| 功能 | 快捷键 |
| --- | --- |
| 折叠 / 展开当前区域 | `⌥ ⌘ [` / `⌥ ⌘ ]` |
| 折叠全部（chord 组合键：先按 ⌘K 再按 ⌘0） | `⌘ K ⌘ 0` |
| Zen 模式（全屏专注写作） | `⌘ K Z` |
| 切换自动换行 | `⌥ Z` |

## 5. 查真实按键（比本文更可靠）

快捷键会随版本、扩展和个人配置变化，以编辑器内查询为准：

- `⌘ K ⌘ S` 打开 **Keyboard Shortcuts** 面板，按功能名搜索任意命令；
- 点击面板顶部的录制图标，按下某个快捷键可查它当前被哪些命令占用（冲突检测）；
- 配套的 [VS Code + Remote SSH + Jupyter](vscode-remote-ssh-jupyter.md) 工作流中，远程窗口的快捷键与本地一致。
