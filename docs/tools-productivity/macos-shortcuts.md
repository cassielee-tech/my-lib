# macOS 快捷键速查


## 应用与窗口

| 功能 | 快捷键 |
| --- | --- |
| 切换到下一个应用 | `⌘ Tab` |
| 反向切换应用 | `⌘ ⇧ Tab` |
| 切换同一应用的窗口 | `⌘` + 反引号键 |
| 关闭当前窗口或标签页 | `⌘ W` |
| 关闭当前应用的所有窗口 | `⌥ ⌘ W` |
| 退出应用 | `⌘ Q` |
| 隐藏当前应用 | `⌘ H` |
| 隐藏其他应用 | `⌥ ⌘ H` |
| 最小化当前窗口 | `⌘ M` |
| 切换全屏 | `⌃ ⌘ F` |
| 强制退出应用 | `⌥ ⌘ Esc` |
| 锁定屏幕 | `⌃ ⌘ Q` |

`⌘ W` 只关闭窗口，应用通常仍在运行；`⌘ Q` 才是退出整个应用。

## 系统导航

| 功能 | 快捷键 |
| --- | --- |
| 打开 Spotlight | `⌘ Space` |
| 打开表情与符号面板 | `⌃ ⌘ Space` 或 `fn E` |
| 打开 Mission Control | `⌃ ↑` |
| 显示当前应用的所有窗口 | `⌃ ↓` |
| 切换左 / 右桌面空间 | `⌃ ←` / `⌃ →` |
| 显示桌面 | `fn F11`（可能需配合系统设置） |

输入法切换经常占用 `⌃ Space` 或 `Caps Lock`。如果快捷键冲突，可前往“系统设置 → 键盘 → 键盘快捷键”修改。

##  通用编辑

| 功能 | 快捷键 |
| --- | --- |
| 复制 / 粘贴 / 剪切 | `⌘ C` / `⌘ V` / `⌘ X` |
| 撤销 / 重做 | `⌘ Z` / `⌘ ⇧ Z` |
| 全选 | `⌘ A` |
| 查找 | `⌘ F` |
| 查找下一个 / 上一个 | `⌘ G` / `⌘ ⇧ G` |
| 保存 | `⌘ S` |
| 打印 | `⌘ P` |
| 打开应用设置 | `⌘ ,` |

## 文本移动与选择

| 功能           | 快捷键             |
| ------------ | --------------- |
| 向左 / 右移动一个单词 | `⌥ ←` / `⌥ →`   |
| 移到行首 / 行尾    | `⌘ ←` / `⌘ →`   |
| 移到文档开头 / 末尾  | `⌘ ↑` / `⌘ ↓`   |
| 向前删除一个单词     | `⌥ ⌫`           |
| 向后删除字符       | `fn ⌫`          |
| 扩展选择         | 在上述移动快捷键中加入 `⇧` |

例如 `⌥ ⇧ ←` 向左选择一个单词，`⌘ ⇧ ↑` 从当前位置选择到文档开头。某些编辑器会重新定义这些按键。

## Finder

| 功能 | 快捷键 |
| --- | --- |
| 新建 Finder 窗口 | `⌘ N` |
| 新建文件夹 | `⌘ ⇧ N` |
| 打开所选项目 | `⌘ O` 或 `⌘ ↓` |
| 返回上级文件夹 | `⌘ ↑` |
| 前往指定文件夹 | `⌘ ⇧ G` |
| 显示所选项目简介 | `⌘ I` |
| 快速查看所选文件 | `Space` |
| 重命名所选项目 | `Return` |
| 移到废纸篓 | `⌘ ⌫` |
| 清倒废纸篓 | `⌘ ⇧ ⌫` |
| 显示 / 隐藏隐藏文件 | `⌘ ⇧ .` |
| 图标 / 列表 / 分栏 / 画廊视图 | `⌘ 1` / `⌘ 2` / `⌘ 3` / `⌘ 4` |

Finder 中按 `Return` 是重命名，不是打开文件；这是从其他系统切换到 macOS 时最容易混淆的地方之一。

快速进到某个文件夹

在访达中按下快捷键 **`Command + Shift + G`**（会弹出一个“前往文件夹”的小窗口），直接把这个路径复制粘贴进去，按回车键就能秒进。
    
在终端里，输入 `open .` 就能直接把当前目录在访达中打开；
反过来，如果你已经在访达里通过上面的方法进到了这个隐藏文件夹，想在终端里操作它，只需在终端输入 `cd` （后面加一个空格），然后**把访达窗口顶部的文件夹图标直接拖进终端窗口里**，路径就自动填好了，按回车即可

## 7. 截图与录屏

| 功能 | 快捷键 |
| --- | --- |
| 截取整个屏幕 | `⌘ ⇧ 3` |
| 截取选定区域 | `⌘ ⇧ 4` |
| 截取窗口 | `⌘ ⇧ 4`，再按 `Space` |
| 打开截图与录屏控制面板 | `⌘ ⇧ 5` |
| 将截图复制到剪贴板 | 在截图组合键中额外按住 `⌃` |

截取区域时：

- 按 `Esc` 取消；
- 拖动过程中按住 `Space`，可以移动选区而不改变大小；
- 截取窗口时按住 `⌥` 再点击，可以排除窗口阴影。
