# macOS 快捷键速查

> 以下使用 Apple 键盘符号。快捷键可能因 macOS 版本、键盘布局、应用和个人设置而变化；应用菜单栏中显示的按键优先级最高。

::: tip 使用建议
把本文当检索工具，不当考试资料。先练 `⌘ Space`、`⌘ Tab`、`⌘ W`、`⌘ Z` 和截图；只有某个重复操作频繁打断工作时，再增加一个对应快捷键。
:::

- [ ] 今天只选择一个新快捷键
- [ ] 把它用于一个真实任务
- [ ] 一周后仍不常用，就不强迫记忆

## 1. 修饰键符号

| 符号 | 名称 | 键盘文字 |
| --- | --- | --- |
| `⌘` | Command | command / cmd |
| `⌥` | Option | option / alt |
| `⌃` | Control | control / ctrl |
| `⇧` | Shift | shift |
| `fn` / `🌐` | Function / Globe | fn / 地球键 |
| `⎋` | Escape | esc |
| `⌫` | Delete | delete |

## 2. 应用与窗口

| 功能 | 快捷键 |
| --- | --- |
| 切换到下一个应用 | `⌘ Tab` |
| 反向切换应用 | `⌘ ⇧ Tab` |
| 切换同一应用的窗口 | `⌘` + 反引号键 |
| 关闭当前窗口或标签页 | `⌘ W` |
| 关闭当前应用的所有窗口 | `⌥ ⌘ W` |
| 退出应用 | `⌘ Q` |
| 隐藏当前应用 | `⌘ H` |
| 隐藏其他应用 | `⌥ ⌘ H` |
| 最小化当前窗口 | `⌘ M` |
| 切换全屏 | `⌃ ⌘ F` |
| 强制退出应用 | `⌥ ⌘ Esc` |
| 锁定屏幕 | `⌃ ⌘ Q` |

`⌘ W` 只关闭窗口，应用通常仍在运行；`⌘ Q` 才是退出整个应用。

## 3. 系统导航

| 功能 | 快捷键 |
| --- | --- |
| 打开 Spotlight | `⌘ Space` |
| 打开表情与符号面板 | `⌃ ⌘ Space` 或 `fn E` |
| 打开 Mission Control | `⌃ ↑` |
| 显示当前应用的所有窗口 | `⌃ ↓` |
| 切换左 / 右桌面空间 | `⌃ ←` / `⌃ →` |
| 显示桌面 | `fn F11`（可能需配合系统设置） |

输入法切换经常占用 `⌃ Space` 或 `Caps Lock`。如果快捷键冲突，可前往“系统设置 → 键盘 → 键盘快捷键”修改。

## 4. 通用编辑

| 功能 | 快捷键 |
| --- | --- |
| 复制 / 粘贴 / 剪切 | `⌘ C` / `⌘ V` / `⌘ X` |
| 撤销 / 重做 | `⌘ Z` / `⌘ ⇧ Z` |
| 全选 | `⌘ A` |
| 查找 | `⌘ F` |
| 查找下一个 / 上一个 | `⌘ G` / `⌘ ⇧ G` |
| 保存 | `⌘ S` |
| 打印 | `⌘ P` |
| 打开应用设置 | `⌘ ,` |

## 5. 文本移动与选择

| 功能 | 快捷键 |
| --- | --- |
| 向左 / 右移动一个单词 | `⌥ ←` / `⌥ →` |
| 移到行首 / 行尾 | `⌘ ←` / `⌘ →` |
| 移到文档开头 / 末尾 | `⌘ ↑` / `⌘ ↓` |
| 向前删除一个单词 | `⌥ ⌫` |
| 向后删除字符 | `fn ⌫` |
| 扩展选择 | 在上述移动快捷键中加入 `⇧` |

例如 `⌥ ⇧ ←` 向左选择一个单词，`⌘ ⇧ ↑` 从当前位置选择到文档开头。某些编辑器会重新定义这些按键。

## 6. Finder

| 功能 | 快捷键 |
| --- | --- |
| 新建 Finder 窗口 | `⌘ N` |
| 新建文件夹 | `⌘ ⇧ N` |
| 打开所选项目 | `⌘ O` 或 `⌘ ↓` |
| 返回上级文件夹 | `⌘ ↑` |
| 前往指定文件夹 | `⌘ ⇧ G` |
| 显示所选项目简介 | `⌘ I` |
| 快速查看所选文件 | `Space` |
| 重命名所选项目 | `Return` |
| 移到废纸篓 | `⌘ ⌫` |
| 清倒废纸篓 | `⌘ ⇧ ⌫` |
| 显示 / 隐藏隐藏文件 | `⌘ ⇧ .` |
| 图标 / 列表 / 分栏 / 画廊视图 | `⌘ 1` / `⌘ 2` / `⌘ 3` / `⌘ 4` |

Finder 中按 `Return` 是重命名，不是打开文件；这是从其他系统切换到 macOS 时最容易混淆的地方之一。

## 7. 截图与录屏

| 功能 | 快捷键 |
| --- | --- |
| 截取整个屏幕 | `⌘ ⇧ 3` |
| 截取选定区域 | `⌘ ⇧ 4` |
| 截取窗口 | `⌘ ⇧ 4`，再按 `Space` |
| 打开截图与录屏控制面板 | `⌘ ⇧ 5` |
| 将截图复制到剪贴板 | 在截图组合键中额外按住 `⌃` |

截取区域时：

- 按 `Esc` 取消；
- 拖动过程中按住 `Space`，可以移动选区而不改变大小；
- 截取窗口时按住 `⌥` 再点击，可以排除窗口阴影。

## 8. 浏览器与文档中常见按键

| 功能 | 快捷键 |
| --- | --- |
| 新建标签页 | `⌘ T` |
| 恢复刚关闭的标签页 | `⌘ ⇧ T` |
| 下一个 / 上一个标签页 | `⌃ Tab` / `⌃ ⇧ Tab` |
| 聚焦地址栏 | `⌘ L` |
| 刷新 | `⌘ R` |
| 放大 / 缩小 / 恢复 | `⌘ +` / `⌘ -` / `⌘ 0` |

这一组属于常见应用约定，不保证所有应用都实现。应以应用菜单栏为准。

## 9. 自定义与排查冲突

前往：

```text
系统设置 → 键盘 → 键盘快捷键
```

可以修改截图、Mission Control、Spotlight、输入法和辅助功能等系统快捷键。排查无效按键时依次检查：

1. 当前键盘布局是否与教程一致；
2. macOS 是否已经占用该组合键；
3. 当前应用菜单栏显示的实际按键；
4. 应用内部是否存在自定义映射；
5. 远程桌面、虚拟机或终端程序是否拦截了按键。
