# Vim 常用按键与技巧

Vim 是模式编辑器：同一按键在不同模式下含义完全不同。核心心法只有两条——**先切模式，再做动作**，以及**操作符 + 动作 = 一次编辑**（如 `d` + `w` 删一个单词）。理解这两条，大部分按键不用背。

## 1. 存活必备

| 功能 | 按键 |
| --- | --- |
| 进入插入模式（光标前 / 光标后 / 下方新开一行） | `i` / `a` / `o` |
| 返回普通模式（任何时候的救命键） | `Esc` 或 `Ctrl-[` |
| 保存 / 退出 | `:w` / `:q` |
| 强制退出（放弃修改） | `:q!` |
| 保存并退出 | `:wq` 或 `ZZ` |
| 放弃修改并重新载入文件 | `:e!` |

## 2. 移动

| 功能 | 按键 |
| --- | --- |
| 左 / 下 / 上 / 右 | `h` / `j` / `k` / `l` |
| 下一个 / 上一个单词开头 | `w` / `b` |
| 单词结尾 | `e` |
| 行首（含缩进）/ 行尾 | `^` / `$` |
| 文件开头 / 结尾 | `gg` / `G` |
| 跳到第 n 行 | `nG` 或 `:n` |
| 当前行内查找字符，光标落在字符上 / 之前 | `f字符` / `t字符` |
| 行内查找反向 | `F` / `T` |
| 重复 / 反向重复上次行内查找 | `;` / `,` |
| 匹配的括号间跳转 | `%` |
| 上 / 下一个空行（按段落移动） | `{` / `}` |
| 当前屏幕居中 / 置顶 / 置底（光标行） | `zz` / `zt` / `zb` |

## 3. 编辑：操作符 + 动作

把编辑拆成"动词 + 名词"：`d` 删、`c` 删并进入插入、`y` 复制，后面接任意动作或文本对象。

| 功能 | 按键 |
| --- | --- |
| 删除字符 / 复制字符 | `x` / `y` |
| 删除 / 复制 / 修改整行 | `dd` / `yy` / `cc` |
| 删到行尾 / 改到行尾 | `D` / `C` |
| 粘贴在光标后 / 前 | `p` / `P` |
| 替换一个字符（不进插入模式） | `r字符` |
| 撤销 / 重做 | `u` / `Ctrl-r` |
| 重复上一次修改（Vim 最强的键） | `.` |
| 合并下一行到当前行 | `J` |

文本对象（`i` = 内部不含边界，`a` = 含边界）：

| 功能 | 按键 |
| --- | --- |
| 当前单词 | `iw` / `aw` |
| 引号内 / 含引号 | `i"` / `a"` |
| 括号内 / 含括号 | `i(` / `a(`（`[` `{` 同理） |
| 函数调用参数 | `i,` 组合如 `ci(` |
| HTML/XML 标签内 / 含标签 | `it` / `at` |

组合示例：`diw` 删单词、`ci"` 改引号内内容、`dt,` 删到逗号前、`yi(` 复制括号内内容、`gg=G` 全文自动缩进。

## 4. 搜索与替换

| 功能 | 按键 |
| --- | --- |
| 向下 / 向上搜索 | `/词` / `?词` |
| 下一个 / 上一个匹配 | `n` / `N` |
| 向下 / 向上搜索光标下的词 | `*` / `#` |
| 取消搜索高亮 | `:noh` |
| 全文替换 | `:%s/旧/新/g` |
| 当前行替换 | `:s/旧/新/g` |
| 逐个确认替换 | `:%s/旧/新/gc` |
| 只替换第 n 到 m 行 | `:n,ms/旧/新/g` |

搜索词中 `.` `*` `[` 等是正则元字符，需转义；开启 `:set magic`（默认）时 `\v` 可切换为"very magic"模式减少转义。

## 5. 可视模式（先选中再操作）

| 功能 | 按键 |
| --- | --- |
| 字符 / 行 / 列选择 | `v` / `V` / `Ctrl-v` |
| 选中后执行操作 | `d` `c` `y` `>` `<` `~` 等 |
| 列选择后多行同时插入（如批量加注释） | `Ctrl-v` 选中 → `I` 输入 → `Esc` |
| 可视模式下交换选中两端 | `o` |
| 重新选中上次选区 | `gv` |

## 6. 实用技巧

### 宏：批量重复任意操作

1. `qa` 开始录制到寄存器 a；
2. 执行一轮编辑动作；
3. `q` 停止录制；
4. `@a` 回放一次，`100@a` 回放 100 次（遇到文件尾自动停止）。

### 寄存器

| 功能 | 按键 |
| --- | --- |
| 复制 / 粘贴到寄存器 a | `"ayy` / `"ap` |
| 复制到系统剪贴板 / 从剪贴板粘贴 | `"+yy` / `"+p` |
| 查看所有寄存器内容 | `:reg` |

`"+` 需要剪贴板支持，先执行 `vim --version | grep clipboard` 确认含 `+clipboard`。

### 标记与跳转

| 功能 | 按键 |
| --- | --- |
| 设置标记 a / 跳回标记 a（精确列 / 行首） | `ma` / `` `a `` / `'a` |
| 跳回上一个位置（配合查看定义后返回） | `` `` `` 或 `Ctrl-o` / `Ctrl-i` |
| 打开光标下的文件名 | `gf` |

### 分屏与标签页

| 功能 | 按键 |
| --- | --- |
| 水平 / 垂直分屏 | `:sp` / `:vs` |
| 在分屏间移动焦点 | `Ctrl-w` + `h/j/k/l` |
| 分屏大小调平 / 只保留当前窗口 | `Ctrl-w =` / `Ctrl-w o` |
| 新建标签页 / 切换标签页 | `:tabnew 文件名` / `gt` `gT` |

### 其他高频小技巧

| 功能 | 按键 |
| --- | --- |
| 当前行及下方整体缩进 / 反缩进 | `>>` / `<<` |
| 切换大小写 / 转大写 / 转小写 | `~` / `gU` + 动作 / `gu` + 动作 |
| 在光标处插入命令输出（如 `:r !date`） | `:r !命令` |
| 命令行历史窗口（搜索历史命令） | `q:` |
| 行数统计等 | `Ctrl-g` |

## 7. 最小可用配置

服务器上没有配置的 Vim 也能用，但加上这几行体验立刻不同（`~/.vimrc`）：

```vim
syntax on
set number
set tabstop=4
set shiftwidth=4
set expandtab
set mouse=a
set clipboard=unnamed
```

`set clipboard=unnamed` 让删除、复制默认走系统剪贴板（macOS / 需剪贴板支持的终端内生效）。

- 配合 [Linux 服务器常用命令速查](linux-server-commands.md) 在远程环境中使用。
