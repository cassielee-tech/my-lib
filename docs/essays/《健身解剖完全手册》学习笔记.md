## 0. 方法论与简化原则

这套系列的方法论一句话：**动作不是抄来的，是推导出来的**。

```text
关节活动（字母表） → 肌肉（谁在做这个活动） → 动作选择与技术（怎么让目标肌肉多干活）
```

一个动作练哪里，不取决于它叫什么名字，而取决于**它让目标肌肉跨越的关节做了什么活动**。推、拉、蹲、举这些俗名只是表象，关节活动才是本质。

套表的口径还有一个重要前提——**这是"健身用的解剖"，不是医学解剖**。作者做了两类删减：

- 删掉健身动作里很少利用的关节活动：各关节的内外旋、髋屈、踝伸（踝背屈）等；
- 删掉参与活动但非训练目标的肌肉：如肩屈时的喙肱肌。

所以这套表比解剖学教材薄一个数量级，但恰好覆盖"练到"所需的全集。


## 1. 关节活动：动作的字母表

第 1 集是整个系列的地基——后面每一块肌肉的功能，都要用这套词汇来描述。

| 关节 | 活动 | 通俗描述 | 单关节动作举例 |
| --- | --- | --- | --- |
| 肩关节 | 屈 | 大臂：后→前 | 前平举 |
| | 伸 | 大臂：前→后 | 直臂下压 |
| | 外展 | 大臂：内→外 | 侧平举 |
| | 内收 | 大臂：外→内 | 龙门架下夹胸 |
| | 水平外展 | 大臂在水平面：内→外 | 蝴蝶机反向飞鸟 |
| | 水平内收 | 大臂在水平面：外→内 | 蝴蝶机夹胸 |
| 肘关节 | 屈 | 肘：打直→折叠 | 弯举 |
| | 伸 | 肘：折叠→打直 | 臂屈伸 |
| 髋关节 | 伸 | 髋：折叠→打直 | 龙门架绳索后踢 |
| 膝关节 | 屈 | 膝：打直→折叠 | 器械腿弯举 |
| | 伸 | 膝：折叠→打直 | 器械腿屈伸 |
| 踝关节 | 足跖屈 | 足背与小腿：折叠→打直 | 提踵 |

两个阅读技巧：

- **"水平"二字是关键**：水平内收/外展发生在大臂抬到与地面平行的高度（如蝴蝶机），与矢状面里的内收（如龙门架下夹胸）是完全不同的动作轨迹，参与的胸肌纤维也不同；
- **被删掉的动作**（内外旋、髋屈、踝伸等）不是不重要，而是增肌动作库很少用到——教材里有，这张表里没有。

## 4. 五条注解的精华

套表作者的原生注解（①～⑤ 对应 A 表上标），每条都是"动作选择"级别的洞察：

**注①：肩屈中的上胸**——胸大肌只有上胸参与肩屈。越是上胸，肌纤维走向越竖直，收缩对肩屈的贡献越大。→ 上胸的专项不只是上斜推，前平举也是。

**注②：肩伸中的肱三头长头**——肱三头肌只有长头参与肩伸，外侧头和内侧头是单关节肌（只管肘关节），不影响肩关节。→ 宽握引体、直臂划船这类肩伸动作里，长头是被"顺带"训练的。

**注③：肩伸中的下胸**——与注①对称：越是下胸，肌纤维越竖直，对肩伸贡献越大。→ 下胸的专项不只是下斜推，仰卧直臂上拉、窄握引体/下拉、器械划船、鹦鹉螺下压都是（B 表注 2 原文）。

**注④：外旋位下的肱二头长头**——肩外展时，若大臂在外旋位（手心朝天），肱二头肌长头恰好处在外展轨迹上，会参与发力。→ 侧平举拇指朝上（外旋位）时二头有感觉，不是错觉。

**注⑤：胸大肌内收的角度分段**——肩内收在外展约 30°～180° 范围主要下胸更有利（龙门架下夹胸的前中程），约 0°～30° 范围中胸更有利（末端）。→ 同一个动作的全程，由不同肌纤维接力完成，这解释了"为什么夹胸要练全程"。

另两条 B 表注解补充双关节肌的次要功能：**肱二头肌还有次要的肩屈**（前平举里能感觉到）；**肱三头长头还有次要的肩伸与肩内收**（一切肩伸练背动作、宽握引体里它都在场）。

## 5. 肩胛骨专题

肩胛骨是"不用专门掌握、但必须知道它在动"的部分：

| 肩胛骨活动 | 通俗描述 | 参与肌肉 |
| --- | --- | --- |
| 上提 | 耸肩 | 上斜方肌、菱形肌、肩胛提肌 |
| 下沉 | 沉肩 | 下斜方肌、背阔肌、胸小肌 |
| 外展（前引） | 肩胛骨远离脊柱 | 前锯肌、胸小肌 |
| 内收（后缩） | 肩胛骨夹向脊柱 | 中斜方肌、下斜方肌、菱形肌 |
| 上旋 | 抬手时肩胛骨向外旋 | 上斜方肌、下斜方肌、前锯肌 |
| 下旋 | 落手时肩胛骨向内旋 | 菱形肌、肩胛提肌、胸小肌 |

**肩胛骨的参与肌肉**

| ![肩胛骨的参与肌肉·图一（图源：套表第 29 页）](/images/essays/anatomy-action-scapula-1.jpg) | ![肩胛骨的参与肌肉·图二（图源：套表第 29 页）](/images/essays/anatomy-action-scapula-2.jpg) |
| --- | --- |

三个要点：

1. **跟随活动**：肩关节的任何动作都会带动肩胛骨跟随活动。专门的肩胛骨训练动作只有两个——**耸肩**（上提）和**后缩肩胛骨的划船**（内收）；
2. **肩肱节律**：肩外展/肩屈大约超过 30° 后，会相伴发生肩胛骨上旋——推举、前平举、侧平举的末端都是上旋在帮忙；
3. **上旋力偶**：上斜方肌、下斜方肌、前锯肌在肩胛骨周围形成环状力偶，共同驱动上旋——三束肌肉方向不同却做同一件事，这就是"力偶"，也因此没有单独练上旋的动作。

## 6. 用矩阵读动作：四个实例

方法论落到实操——拿到任何动作，先问"它让目标关节做了什么活动"，再回矩阵查肌肉。

**实例一：宽握 vs 窄握引体，练的为什么不一样？**
背阔肌有两个功能：伸（大臂前→后）与内收（大臂外→内）。宽握时大臂外展位、发力以"拉向身体中线"为主——走内收线；窄握时大臂在体前、发力以"拉向身体后方"为主——走伸线。所以宽握引体/下拉标注在"内收"格，窄握标注在"伸"格。这也顺带解释了注③：窄握引体里下胸有参与感，因为下胸是肩伸肌。

**实例二：龙门架下夹胸的全程。**
内收动作，但不是匀速的同一批纤维：前中程（大臂外展角度大）下胸更有利，末端（大臂贴近身体）中胸更有利。动作顶部不要偷行程——最后 30° 是中胸的主场。

**实例三：蝴蝶机正坐 vs 反坐。**
同一台机器，正坐做水平内收（上胸、中胸、下胸、肩前束），反坐做水平外展（肩后束、冈下肌）——互为拮抗的两群肌肉，一台机器全包。这是"水平屈伸"从字母表落地成器械设计的标准案例。

**实例四：直臂下压为什么是背阔肌孤立动作？**
它是"肩伸"的单关节动作举例：肘关节全程不动（屈伸为零），只有肩关节做伸——背阔肌、大圆肌直接发力，肱二头肌无法代偿（它只能屈肘或辅助肩屈）。想找背阔肌发力感，先练它。

## 7. 待补全：核心肌群

> 本节套表未覆盖，按同一矩阵框架补充；待系列后续集数更新后对齐。

核心在矩阵里的特殊性：**它在多数动作里的角色不是"产生关节活动"，而是"抗住关节活动"**——把躯干变成刚性平台，让力从下肢传到上肢。因此核心的矩阵是"抗"字头的：

| 核心功能 | 参与肌肉 | 代表动作 |
| --- | --- | --- |
| 脊柱屈（主动） | 腹直肌 | 卷腹 |
| 抗伸展 | 腹直肌、腹斜肌、腹横肌 | 平板支撑、死虫式 |
| 抗旋转 | 腹斜肌、腹横肌 | 帕洛夫推 |
| 抗侧屈 | 腰方肌、腹斜肌 | 侧平板、单侧农夫行走 |

深蹲、硬拉、推举里竖脊肌做的是等长稳定（抗屈），所以"练核心"大部分时候不需要卷腹，需要的是**在各种负重姿势下躯干不变形**。
