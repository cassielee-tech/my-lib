# 第 2 章｜张量、矩阵乘法、计算图与反向传播

## 本章导学

::: tip 本章核心结论
1. 张量是多维数据，Shape 描述每个维度的含义和大小。
2. 矩阵乘法能否执行，先检查左矩阵最后一维是否等于右矩阵倒数第二维。
3. 反向传播沿计算图反向应用链式法则，同时产生输入梯度和参数梯度。
:::

## 本章要解决的问题

Transformer 里几乎所有复杂结构，最终都可以拆成张量运算。要理解模型、算子和集合通信，首先要形成三个习惯：

1. 看到运算先写出每个张量的 **shape**；
2. 看到 shape 就能判断数据如何流动、能否完成运算；
3. 不只看前向结果，还要追踪反向传播产生的梯度。

## 开始前：为什么要学这几个概念

大模型代码看起来包含 Attention、Embedding、Normalization 等很多模块，但加速器真正执行的仍是更基础的运算：矩阵乘法、加法、乘法、归约和数据搬运。

本章相当于学习大模型系统的“机器指令级思维”：

- **张量**告诉我们数据长什么样；
- **shape**告诉我们数据各维代表什么；
- **矩阵乘法**是 Transformer 消耗计算量最多的操作之一；
- **计算图**记录运算依赖；
- **反向传播**沿依赖关系计算梯度；
- **梯度张量**最终会成为数据并行中的通信对象。

### 从后端代码理解张量

后端开发中，我们经常定义结构化数据：

```text
List<Request> requests
Request.tokens
Token.embedding
```

在深度学习中，为了让硬件高效批量计算，这些嵌套对象通常不会以对象形式保存，而会排成一块连续、多维的数据：

```text
[请求数量, 每个请求的 Token 数, 每个 Token 的向量长度]
```

这就是 `[batch, sequence, hidden]` 张量。Shape 可以看成这段连续数据的“解释方式”。
