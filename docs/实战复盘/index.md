## 阅读提示

- **先读课程再读复盘**：各篇都以[HCCL 与 HCOMM 源码课程](/通信与昇腾/源码课程/index.md)的分层、注册与建链流程为底，跨不过去时先补[单元 1](/通信与昇腾/源码课程/01-architecture-layering.md)、[单元 2](/通信与昇腾/源码课程/02-control-plane.md)；
- **按"结论 → 全景 → 细节"读**：每篇开头都有先记住的结论清单，赶时间只读结论 + 方法论清单；
- **复盘与交付物对照读**：复盘讲脉络，交付物（同目录）是当时的第一手记录——决策记录、风险表、用例台账都在里面；
- **方法论可平移**：影响面矩阵、参考实现三问、wire 契约意识、对照实验、rebase 三同步、"计价必须与执行分流同口径"，换一个需求照样能用。
- **排障方法论**：三阶段定界、EI 错误码全表与八类排障决策树见[深度参考·排障手册](/通信与昇腾/参考手册/排障手册/)——复盘记录真实案例，手册回答"这类问题按什么流程查"。

## 交付物命名约定

- **需求迭代**：外层按迭代组织（当前 `26RP4/`）；需求目录 `NN-需求简称`，`NN` 按立项顺序编号。
- **需求文档**：类型编号固定——`01-预调研`、`02-前置知识`、`03-SE设计`、`04-SRS_SD`、`05-STC`、`06-SRS_SD评审`、`07-代码评审`、`08-问题对齐`、`09-经验总结`；某需求没有的类型直接缺号，不为连续而重排。
- **问题修复**：`NN-主题`，按修复顺序编号。
- **模板**：`NN-模板名` 只表示模板清单顺序，与需求文档的类型号无关。
