# 第 6 章｜Eager、计算图与图编译

> 本课目标：说清 Eager 模式下一行模型代码的完整执行链路与三层开销；区分动态图与静态图；理解 torch.compile 与 GE 图模式的编译流水线及收益来源；知道图编译的代价与适用边界。

## 本章导学

::: tip 本课只记住 3 件事
1. Eager 每步即时执行——灵活、好调试，但每步都付 Python/分发/Launch 开销，且**没有全局优化视角**。
2. 计算图把整段计算记录成"工序依赖图"，编译器由此看见全局：**融合、内存复用、整图下发**都是图视角的产物。
3. 图编译有代价：编译耗时、guard 失效重编译、动态控制流受限——**模式选择是权衡，不是信仰**。
:::

**学习节奏：** 本章拆为 **4 个学习单元，每个约 15 分钟**。先走一遍 Eager 的执行链路，再看图视角带来什么，然后进入编译流水线，最后划清边界。

**跟不动？** 先读 [⚡ 速通版（约 5 分钟）](06-eager-graph-compilation/quick.md)：一个"装修队现场干 vs 先画施工图"的类比讲完整章，再回来按单元深入。
