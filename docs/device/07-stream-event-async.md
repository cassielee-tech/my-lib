# 第 7 章｜Stream、Event 与异步执行

> 本课目标：理解 Host 与 Device 的异步协作模型；说清 Stream 的顺序语义与多流并行的条件；掌握 Event 与各类同步对象的适用层次；能分析并设计计算、搬运、通信的任务重叠。

## 本章导学

::: tip 本课只记住 3 件事
1. Host 只负责**提交**任务，设备**排队异步执行**——调用返回不等于执行完成，这是所有后续概念的前提。
2. Stream 是任务的单行道：**同流严格按序，跨流才可能并行**；想重叠，先确认任务之间真的没有依赖。
3. 同步是必要之恶：**漏同步是偶发错误，滥同步是隐形减速**——用 Event 精确声明依赖，用 synchronize 兜底。
:::

**学习节奏：** 本章拆为 **4 个学习单元，每个约 15 分钟**。先接受"异步"这个心智模型，再认识 Stream 和 Event 两件工具，最后把重叠工程化。

**跟不动？** 先读 [⚡ 速通版（约 5 分钟）](07-stream-event-async/quick.md)：一个"工地车道与签认单"的类比讲完整章，再回来按单元深入。
