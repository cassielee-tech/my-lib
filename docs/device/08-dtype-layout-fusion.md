# 第 8 章｜数据类型、布局与算子融合

> 本课目标：掌握主流数据类型的构成与取舍，能按对象选择混合精度方案；理解 Layout 的系统代价与隐式转换的隐形开销；分清三类融合手艺、收益账与适用边界。本课是第二阶段收官。

## 本章导学

::: tip 本课只记住 3 件事
1. 数据类型是"范围、精度、位宽"的三角交换：**位宽直接改写显存与带宽账本，但计算提速要看矩阵单元的档位支持**。
2. 布局决定硬件读数据的效率：**转置/Reformat 是真实的读写开销**，隐式转换是图编译里最常见的隐形账单。
3. 融合的本质是第 5 章的"向右挪"：**逐元素链和 Norm 链最值得融，两个大 GEMM 之间通常不值得**。
:::

**学习节奏：** 本章拆为 **4 个学习单元，每个约 15 分钟**。先认识数据类型这个"最大杠杆"，再学按对象混用精度，然后回到布局账单，最后把融合工程化并收官第二阶段。

**跟不动？** 先读 [⚡ 速通版（约 5 分钟）](08-dtype-layout-fusion/quick.md)：一个"建材规格与码放"的类比讲完整章，再回来按单元深入。

- [ ] 我能说出 FP16 与 BF16 的区别和各自的适用场景
- [ ] 我能列出训练中各对象（权重/梯度/优化器状态/激活）的典型精度组合
- [ ] 我能判断一段计算"该不该融合"，并说出收益方向
