# HCCL 环境变量参考

> HCCL 提供约 40 个环境变量，分**六大类**：功能 / 性能 / 网络 / 调试 / 可靠性 / 安全。配置优先级：**通信域级别（`HcclCommConfig`）> 环境变量 > 默认值**（见 [../communicator/配置.md](/通信与昇腾/参考手册/通信域/配置.md)）。
>
> 事实来源：`hccl/docs/zh/user_guide/hccl_env/`（各环境变量文档 + 六大分类 README）。生效值可在 CANN 日志 run/plog 中检索 `HCCL_ENV` 查询。

---

## 1. 功能相关

| 环境变量 | 作用 | 默认/取值 |
| --- | --- | --- |
| `HCCL_CONNECT_TIMEOUT` | 建链阶段超时（建议 < `HCCL_EXEC_TIMEOUT`） | 120s |
| `HCCL_EXEC_TIMEOUT` | 执行阶段超时 | 1836s |
| `HCCL_ALGO` | Server 间/超节点间通信算法（指定后自适应选择不生效）；语法 `level1:alg` 等 | 自适应 |
| `HCCL_BUFFSIZE` | 共享数据缓存区大小（MB） | 200 |
| `HCCL_INTRA_PCIE_ENABLE` | Server 内是否使能 PCIe 链路 | 1 |
| `HCCL_INTRA_ROCE_ENABLE` | Server 内是否改走 RoCE 环路（异构子框建链失败处置） | 0 |
| `HCCL_INTER_HCCS_DISABLE` | 超节点内改用 RDMA 通信（禁用 HCCS，此时 device_ip 必配） | FALSE |
| `HCCL_OP_EXPANSION_MODE` | 算子展开模式（引擎）：AI_CPU/AICPU_TS/AIV/CCU_MS/CCU_SCHED/HOST/HOST_TS/AICPU_CacheDisable | 按产品（950→AICPU_TS，A3→AI_CPU，A2→HOST） |
| `HCCL_DETERMINISTIC` | 确定性计算开关（false/true/strict） | false（950 归约类强制确定性） |
| `HCCL_LOGIC_SUPERPOD_ID` | 逻辑超节点划分 ID | 0 |

> `HCCL_OP_EXPANSION_MODE` 详解见 [../engine/README.md §5](/通信与昇腾/参考手册/通信引擎/)；`HCCL_ALGO` 语法见 [../algorithms/algo_selector.md](/通信与昇腾/参考手册/算法参考/algo_selector.md)；`HCCL_DETERMINISTIC` 见 [reliability_security.md](/通信与昇腾/参考手册/运行与约束/可靠性与安全.md)。

## 2. 性能相关

| 环境变量 | 作用 | 默认/取值 |
| --- | --- | --- |
| `HCCL_RDMA_PCIE_DIRECT_POST_NOSTRICT` | PCIe 直发非严格模式（rdmaFastPost） | EmptyString |
| `HCCL_RDMA_QPS_PER_CONNECTION` | 每连接 QP 数 | 1 |
| `HCCL_RDMA_QP_PORT_CONFIG_PATH` | QP 端口配置路径（多 QP 源端口） | 空 |
| `HCCL_HOST_RDMA_UDP_PORTS_LIST` | Host RDMA UDP 端口列表 | — |
| `HCCL_MULTI_QP_THRESHOLD` | 多 QP 阈值 | 512KB |
| `HCCL_ALG_MULTIPLE_DIMENSION_SPLIT_RATIO` | 多维度切分比例 | — |
| `HCCL_UB_MULTI_CHANNEL_NUM` | UB 多 Channel 数（多平面/多 Jetty） | — |

> RDMA 调优详见 [../comm/roce_rdma.md §8](/通信与昇腾/参考手册/协议与传输/roce_rdma.md)；多平面多 Jetty 详见 [../networking/多平面网络.md](/通信与昇腾/参考手册/组网形态/多平面网络.md)。

## 3. 网络相关

| 环境变量 | 作用 | 默认/取值 |
| --- | --- | --- |
| `HCCL_IF_IP` | Host 通信 IP（与 root 节点通信，IPv4/IPv6，仅一个） | 未设置 |
| `HCCL_IF_BASE_PORT` | Host 通信基础端口 | 60000 |
| `HCCL_HOST_SOCKET_PORT_RANGE` | Host 侧通信端口范围（单卡多进程，可设 auto） | — |
| `HCCL_NPU_SOCKET_PORT_RANGE` | NPU 侧通信端口范围（单卡多进程，可设 auto） | — |
| `HCCL_SOCKET_IFNAME` | 通信网卡名（4 种匹配规格：`=`/`^=`/前缀/`^`前缀） | EmptyString |
| `HCCL_SOCKET_FAMILY` | 网卡 IP 协议版本（AF_INET/AF_INET6） | AF_INET |
| `HCCL_RDMA_TC` | RDMA traffic class（RoCE v2 对应 ToS，÷4=DSCP） | 132 |
| `HCCL_RDMA_SL` | RDMA service level（须与网卡 PFC 优先级一致） | 4 |
| `HCCL_RDMA_TIMEOUT` | RDMA 超时 | 20 |
| `HCCL_RDMA_RETRY_CNT` | RDMA 重试次数 | 7 |
| `HCOMM_TA_CTP_UB_TIMEOUT` | UB_CTP 传输超时 | — |
| `HCOMM_TA_RTP_UB_TIMEOUT` | UB_RTP 传输超时 | — |
| `HCOMM_TA_RTP_UBOE_TIMEOUT` | UBoE 传输超时 | — |

> 网卡选择优先级：`HCCL_IF_IP` > `HCCL_SOCKET_IFNAME` > 自动（docker/lo 以外网卡字典序升序 > docker 网卡 > lo 网卡）。详见 [../communicator/创建方式.md §2.3](/通信与昇腾/参考手册/通信域/创建方式.md)。

## 4. 调试相关

| 环境变量 | 作用 | 默认/取值 |
| --- | --- | --- |
| `HCCL_DIAGNOSE_ENABLE` | task 级信息跟踪开关（A3/A2 需手动开启） | 0 |
| `HCCL_ENTRY_LOG_ENABLE` | 算子级入参记录（集群行为一致性比对） | 0 |
| `HCCL_DEBUG_CONFIG` | 模块级日志开关（仅 A3/A2，分析算法选择/任务编排） | 0x0 |
| `HCOMM_DEBUG_CONFIG` | HCOMM 模块级日志开关 | — |
| `HCCL_DFS_CONFIG` | 高级故障探测配置（建议保持默认） | — |

> 调试环境变量详见 [../debug/README.md §5](/通信与昇腾/参考手册/排障手册/)。

## 5. 可靠性相关

| 环境变量 | 作用 | 默认/取值 |
| --- | --- | --- |
| `HCCL_OP_RETRY_ENABLE` | 算子重执行开关，按层级独立配置 `"L0:0,L1:1,L2:1"` | L0:0,L1:0,L2:0 |
| `HCCL_OP_RETRY_PARAMS` | 重执行参数 `MaxCnt/HoldTime/IntervalTime` | MaxCnt:1, HoldTime:5000ms, IntervalTime:1000ms |

> 重执行仅 A3 支持，详见 [reliability_security.md](/通信与昇腾/参考手册/运行与约束/可靠性与安全.md)；重执行对整网性能影响见 `comm_retry_perf_impact.md`。

> 白名单与 TLS 加密详见 [reliability_security.md §3](/通信与昇腾/参考手册/运行与约束/可靠性与安全.md)。
