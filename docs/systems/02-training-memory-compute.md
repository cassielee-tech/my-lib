# 第 2 章｜训练显存与计算优化

> 本课目标：算清训练显存的四个大件（权重、梯度、优化器状态、激活）各自占多少、谁随什么增长；掌握 Activation Checkpointing、混合精度、梯度累积和 Offload 四件工具各自节省什么、付出什么；能建立显存规划与 OOM 排查的工作流。

## 本章导学

::: tip 本课只记住 3 件事
1. 训练显存 = **权重 + 梯度 + 优化器状态 + 激活**：前三个随参数量线性（混合精度下约 16 字节/参数），**激活是唯一随 B×S×层数疯长的大件**。
2. 四件工具各救一个大件、各付一笔账：**AC 用时间换激活、混合精度直接减字节、梯度累积用批次换峰值、Offload 用位置换空间**。
3. OOM 排查先算账再动手：**先定位哪个大件在涨、峰值落在哪一步**，再按"工具—账单"对照表选手段。
:::

**学习节奏：** 本章拆为 **4 个学习单元，每个约 15 分钟**。先建立账本，再逐件学工具，最后打组合拳。

**跟不动？** 先读 [⚡ 速通版（约 5 分钟）](02-training-memory-compute/quick.md)：一个"书桌空间管理"的类比讲完整章，再回来按单元深入。
