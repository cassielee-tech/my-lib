# 第 3 章｜存储层次与数据搬运

> 本课目标：说清 HBM、Cache、片上 Buffer 和寄存器的区别与联系；解释数据搬运为什么经常比计算更贵；掌握局部性与复用这两种降低搬运成本的基本思路，为第 4 课的 Tiling 与流水线做准备。

## 本章导学

::: tip 本课只记住 3 件事
1. 存储是金字塔：越靠近计算单元，越快、越小、越贵；没有一层能同时做到"大、快、便宜"。
2. 搬一字节的能耗和延迟远高于算一次乘加——让数据少动、复用，是所有性能优化的底层逻辑。
3. 同一个物理规律在 GPU 和 NPU 上都成立，差异只在片上存储由谁管理（硬件缓存 vs 软件显式搬运）。
:::

**学习节奏：** 本章拆为 **4 个学习单元，每个约 15 分钟**。先建立金字塔模型，再逐层认识每一级存储，然后量化搬运代价，最后落到局部性与复用的优化思路。

## 这一课在整条路线中的位置

第 2 章解释了计算单元怎样组织（Warp、Cube/Vector），本章解释这些单元的数据从哪里来。第 1 章埋下的伏笔——算术强度 $AI=FLOPs/Bytes$——在本章得到物理解释：分母里的每个 Byte 都要真实地经过存储层次。下一课的 Tiling 与流水线，本质就是把本章的"复用"思想工程化。
