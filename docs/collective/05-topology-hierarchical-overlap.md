# 第 5 章｜拓扑、分层通信与通信计算重叠

> 本课目标：把前四章的算法放回真实硬件的两层世界（机内高速 + 机间低速）；理解分层通信为什么快、chunk/channel 如何兑现理论带宽、重叠如何把通信藏进计算，完成《集合通信》收官。

## 本章导学

::: tip 本课只记住 3 件事
1. **拓扑是隐藏的第三维**：机内全互联（HCCS/NVLink，百 GB/s 级）与机间交换网（PCIe/RoCE/IB，差近一个量级）——逻辑 rank 的排布必须贴着物理拓扑，否则贵链路搬冤枉字节。
2. **分层的本质**：让贵链路少搬字节——机间流量从"每卡一份"降到"每节点一份"；分层是拓扑感知的显式形式，且每层可以各选算法。
3. **三板斧兑现账本**：**Chunk** 拆小铺流水、**Channel** 多路并行、**重叠**藏进计算——理论带宽和实测带宽之间的差距，靠它们补。
:::

**学习节奏：** 本章拆为 **4 个学习单元，每个约 15 分钟**。本章是《集合通信》收官课，读完建议回到 [课程总览](../roadmap.md) 做一次验收。

**跟不动？** 先读 [⚡ 速通版（约 5 分钟）](05-topology-hierarchical-overlap/quick.md)：一个"物流网络"的类比讲完整章，再回来按单元深入。

- [ ] 我能说出机内/机间链路的量级差，以及它对 rank 排布的要求
- [ ] 我能算出分层方案把机间流量降多少倍
- [ ] 我能说出 chunk、channel、重叠各自解决什么、代价是什么
