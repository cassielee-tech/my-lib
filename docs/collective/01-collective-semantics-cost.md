# 第 1 章｜Collective 语义与通信代价模型

> 本课目标：建立通信的坐标系（Rank、通信域、消息）；逐个吃透六个核心原语的输入输出与语义恒等式；掌握 α-β-γ 代价模型，能对任何一次通信算三本账；能按消息大小、rank 数、拓扑初步选择原语与算法。

## 本章导学

::: tip 本课只记住 3 件事
1. 集合通信原语只问三件事：**输入是什么、输出是什么、谁在结束时拿到什么**——语义先于算法。
2. 一条黄金恒等式：**AllReduce = Reduce + Broadcast = ReduceScatter + AllGather**——后面所有算法推导都从它出发。
3. 每次通信都有三本账：**T ≈ α×轮次 + β×字节 + γ×计算**——小消息被 α 主导，大消息被 β 主导，这决定了后面的算法选型。
:::

**学习节奏：** 本章拆为 **4 个学习单元，每个约 15 分钟**。先立坐标系，再认全六个原语，然后学会算账，最后做第一次选型练习。

**跟不动？** 先读 [⚡ 速通版（约 5 分钟）](01-collective-semantics-cost/quick.md)：一个"办公室协作动作"的类比讲完整章，再回来按单元深入。

- [ ] 我能写出并解释 AllReduce 的两种分解
